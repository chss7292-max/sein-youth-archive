# 세인교회 제1청년부 사이트 초안

이 폴더는 다른 컴퓨터에서 이어서 편집하거나 Vercel에 배포할 수 있는 정적 웹사이트 파일입니다.

- `index.html`: 반응형 사이트 화면
- `sein-church-logo.png`: 세인교회 로고
- `기획서.md`: 기능 및 운영 기획
- `vercel.json`: 정적 사이트 설정

`index.html`을 브라우저에서 열면 미리볼 수 있습니다. 로그인, 권한 검증, 문서 저장과 댓글 저장은 아직 서버에 연결되지 않은 시연용입니다.
